# Standard-Farbe B (Blau-Kanal)

Blauwert der Standard-Farbe für den Neustart (0-255).

Dieser Parameter ist nur sichtbar wenn:
- **Global:** "Verhalten nach Neustart (Global)" = "Standard-Farbe"
- **Segment:** "Verhalten nach Neustart" = "Standard-Farbe (eigene)"

**Wertebereich:** 0-255
- 0 = kein Blau
- 255 = maximales Blau

**Standardwert:** 255 (volle Helligkeit)

**Hinweis:** Zusammen mit R, G und W ergibt sich die RGBW-Farbe beim Neustart.
