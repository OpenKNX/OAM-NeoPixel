# HCL Start – Stunde

Stunde der **Startzeit** für den **zeitbasierten HCL‑Modus**.

## Gültig wenn
- **HCL Kurve Typ = Zeit**

## Werte
- **0…23**

## Bedeutung
Zusammen mit **„HCL Start – Minute“** ergibt sich die Startzeit im Format **HH:MM**.
Ab dieser Uhrzeit beginnt die HCL‑Kurve (z. B. von kalt nach warm, abhängig von Min/Max‑Kelvin).
