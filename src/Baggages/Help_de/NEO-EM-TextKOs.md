# Effekt-Text KOs aktivieren

Aktiviert die Effekt-Text-Kommunikationsobjekte für diesen Effektmanager.

Nötig, wenn ein Cue den Effekt **Laufschrift** verwendet und der angezeigte Text
zur Laufzeit per KNX-Telegramm (DPT 16.001) geändert werden soll. Ist die Option
aus, bleiben die Text-KOs ausgeblendet.
