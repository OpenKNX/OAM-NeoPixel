# Anzeigemodus

**Effekt:** Uhr 2D

Anzeigemodus: 0=Digital, 1=Binär BCD-Spalten, 2=Binär Zeilen, 3=Auto-Wechsel Digital/Binär (BCD), 4=Auto-Wechsel Digital/Binär (Zeilen). Intervall siehe SwitchSec.

**Auswahl:**

* 0 = Digital
* 1 = Binär BCD-Spalten
* 2 = Binär Zeilen
* 3 = Auto-Wechsel (BCD)
* 4 = Auto-Wechsel (Zeilen)

**Standardwert:** 0 = Digital
