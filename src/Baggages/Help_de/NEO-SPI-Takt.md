# SPI Takt

Konfiguration der SPI Clock-Frequenz für SPI-basierte LED-Streifen.

## Automatisch (empfohlen)
Die SPI Clock-Frequenz wird automatisch basierend auf dem gewählten LED-Typ optimiert.

## Manuell
Ermöglicht die manuelle Konfiguration der SPI Clock-Frequenz. Diese Option ist nur für fortgeschrittene Benutzer gedacht, die spezifische Timing-Anforderungen haben.

Bei manueller Einstellung wird ein zusätzliches Dropdown für die Clock-Frequenz angezeigt.
