# HCL Helligkeitskompensation

Kompensiert subjektive Helligkeitsunterschiede über die Farbtemperatur.
Warmweiß wirkt oft dunkler als Kaltweiß – dieser Parameter kann das ausgleichen.

## Werte
- **0…100 %**
- Default: **100 %**

## Interpretation (empfohlen)
- **100 %:** volle Kompensation (neutraler Helligkeitseindruck)
- **0 %:** keine Kompensation (Helligkeit bleibt rein aus RGB/RGBW ohne Kelvin‑Kompensation)

## Hinweis
Je nach LED‑Typ (RGB vs. RGBW) kann eine moderate Reduktion (z.B. 70–90 %) natürlicher wirken.
