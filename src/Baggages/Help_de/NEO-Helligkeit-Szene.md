# Helligkeit

Helligkeit der Szene (0-255).

Der Abruf schaltet das Segment mit dieser Helligkeit ein (die globale Helligkeit wirkt zusätzlich). **0** ist eine Aus-Szene: Das Segment wird ausgeschaltet, Effekt und Farbe der Szene werden nicht übernommen, die eingestellte Helligkeit bleibt für das nächste EIN erhalten. Wird eine Szene auf einem ausgeschalteten Segment gelernt, wird Helligkeit 0 gespeichert.
