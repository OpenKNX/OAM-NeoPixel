# Standard-Farbe G (Grün-Kanal)

Grünwert der Standard-Farbe für den Neustart (0-255).

Dieser Parameter ist nur sichtbar wenn:
- **Global:** "Verhalten nach Neustart (Global)" = "Standard-Farbe"
- **Segment:** "Verhalten nach Neustart" = "Standard-Farbe (eigene)"

**Wertebereich:** 0-255
- 0 = kein Grün
- 255 = maximales Grün

**Standardwert:** 255 (volle Helligkeit)

**Hinweis:** Zusammen mit R, B und W ergibt sich die RGBW-Farbe beim Neustart.
