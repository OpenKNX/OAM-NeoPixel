# HCL Anwendungsmodus

Bestimmt, **worauf HCL angewendet wird**.

## Werte
- **Nur Weiß (0):** HCL wirkt vor allem auf weiß/entsättigte Pixel (farben werden geschont) *(empfohlen)*
- **Alle Farben (1):** HCL kann auch farbige Pixel in Richtung Kelvin‑Weißpunkt verschieben (kann bunte Szenen sichtbar verändern)

## Empfehlung
- Für Wohnraum/„Circadian“-Licht: **Nur Weiß**
- Für reine Weißlicht‑Strips oder wenn Farben egal sind: **Alle Farben**
