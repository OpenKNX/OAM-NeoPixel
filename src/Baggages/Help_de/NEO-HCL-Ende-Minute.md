# HCL Ende – Minute

Minute der **Endzeit** für den **zeitbasierten HCL‑Modus**.

## Gültig wenn
- **HCL-Kurvetyp = Zeit**

## Werte
- **0…59**

## Bedeutung
Zusammen mit **„HCL Ende – Stunde“** ergibt sich die Endzeit im Format **HH:MM**.

## Hinweis (über Mitternacht)
Wenn Endzeit < Startzeit ist, wird das Zeitfenster üblicherweise **über Mitternacht** interpretiert (abhängig von Implementierung).
