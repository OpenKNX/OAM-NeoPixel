# Richtung

**Effekt:** Wipe

Richtung (0-5): 0=Links→Rechts, 1=Rechts→Links, 2=Oben→Unten, 3=Unten→Oben (2/3 zeilenweise auf einer 2D-Matrix, sonst wie 0), 4=Mitte→Außen, 5=Außen→Mitte

**Auswahl:**

* 0 = Links nach rechts
* 1 = Rechts nach links
* 2 = Oben nach unten
* 3 = Unten nach oben
* 4 = Mitte nach aussen
* 5 = Aussen nach Mitte

**Standardwert:** 0 = Links nach rechts
