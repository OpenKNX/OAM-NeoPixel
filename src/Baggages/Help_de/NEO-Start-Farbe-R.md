# Standard-Farbe R (Rot-Kanal)

Rotwert der Standard-Farbe für den Neustart (0-255).

Dieser Parameter ist nur sichtbar wenn:
- **Global:** "Verhalten nach Neustart (Global)" = "Standard-Farbe"
- **Segment:** "Verhalten nach Neustart" = "Standard-Farbe (eigene)"

**Wertebereich:** 0-255
- 0 = kein Rot
- 255 = maximales Rot

**Standardwert:** 255 (volle Helligkeit)

**Hinweis:** Zusammen mit G, B und W ergibt sich die RGBW-Farbe beim Neustart.
