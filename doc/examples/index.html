3. Import in der ETS

  1. Applikation OpenKNX NeoPixel (Release oder Dev) einfügen, Parameter öffnen.
  2. Seite Konfigurationstransfer → Import öffnen.
  3. String kopieren und in Transfer-String einfügen, Import-Ziel: „automatisch aus Export übernehmen“.
  4. Importieren; Resultat [OK] prüfen (Dev-Applikation: bei LED-Streifen und Effektmanager [OK; Version "-" -> undefined], nur ein Hinweis).
  5. Alle Strings in der angezeigten Reihenfolge, je Gerät. Danach die Punkte „Nach dem Import prüfen“ erledigen (vor allem Ports) und herunterladen.

Jeder String setzt alle nicht enthaltenen Parameter seines Kanals auf den Standardwert. Gruppenadressen, KO-Flags und Ports werden nicht übertragen. Ports erst nach dem Import wählen.

RGB-Streifen (z. B. WS2812B, Farbordnung GRB) haben keinen Weißkanal: Weiß entsteht aus der RGB-Farbe, ein W-Wert wird nicht geschrieben. RGBW-Streifen (z. B. SK6812, Farbordnung GRBW) bekommen Weiß über W.

5. Gruppenadressen (Vorschlag)

Hauptgruppe und Mittelgruppen-Basis aus den Einstellungen; Gruppe 0/0/x (Uhrzeit, Datum) bleibt zentral. KO-Flags: C = Kommunikation, R = Lesen, W = Schreiben, T = Übertragen, U = Aktualisieren, I = Initialisierung.
